# Kingdom Come: Deliverance II

From a ~130-mod setup on game 1.5.6, built on Opetank's **Hussitesque** collection. The full setup, with credits and lessons, is at [lovelessgaming.com/mods/kcd2](https://lovelessgaming.com/mods/kcd2/).

| File | What it is |
|---|---|
| [`user.cfg`](user.cfg) | Tuned config: view distance, shadows/AO, memory and streaming, no blur or vignette. Folds five config-only mods into one file to free mod slots. Credits inside. |
| [`key-scheme.md`](key-scheme.md) | A key layout where Camping, Minimap, Companion, Enhanced GI, Weather, Pull Hood, Noclip and QuickSave stop fighting over F6 to F8. |
| [`small-fixes.md`](small-fixes.md) | Version-disabled mods, "not found" mods, the launch crash with 120+ mods, KCSE breaking, a Galahad perk-point schedule, harmless log noise. |
| [`experimental/`](experimental/) | Console scripts to raise levels or unlock perks, combos and recipes. **Untested**: back up saves first. |

**Coming:** a builder script that merges the keybind and other overlapping files from *your* installed mods into one last-loading patch (the fix for "only one mod's hotkeys work").

**Tool:** the [KCD2 Console](https://github.com/ResurexXxion/loveless-mod-consoles/tree/main/kcd2) is how these problems were found: it reads the game's logs live.
